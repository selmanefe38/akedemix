VICTORY

GTA VI'nın Xbox Series X|S sürümünü Windows üzerinde çalıştırmayı hedefleyen deneysel açık kaynak projesi.

GitHub Projesini Aç Kurulum Rehberi

VIctory Nedir?

VIctory, Xbox Series X|S için hazırlanmış GTA VI sürümünü Windows ortamında çalıştırmayı amaçlayan deneysel bir projedir. Proje, oyunun Xbox sürümünü doğrudan Windows'ta çalıştırabilmek için gerekli uyumluluk ve çeviri işlemlerini gerçekleştirmeye çalışır.

Projenin amacı

  • Xbox oyun kodunun Windows ortamında çalıştırılmasını sağlamak.
  • Grafik işlemlerini Windows ve DirectX 12 ile uyumlu hâle getirmek.
  • Xbox'a özel shader ve grafik işleme sistemlerini çevirmek.
  • Oyunun Windows üzerinde çalışabilmesi için gerekli altyapıyı geliştirmek.
Önemli: Proje henüz oynanabilir değil.

24 Kasım 2026 tarihli proje açıklamasına göre oyun açılabiliyor, menüler görüntülenebiliyor ve oyun dünyası yüklenebiliyor. Ancak performans ve grafik sorunları nedeniyle normal şekilde oynanabilecek durumda değil.

Sistem Gereksinimleri

Projenin çalışması için aşağıdaki yazılım ve donanım özellikleri gereklidir. Bunlar projenin teknik gereksinimleridir; oyunun sorunsuz çalışacağını garanti etmez.

İşletim sistemi

Windows 10 veya Windows 11, 64-bit.

İşlemci

AVX2 komut setini destekleyen işlemci.

Ekran kartı

Direct3D 12, Shader Model 6.6 ve mesh shader desteği.

Depolama ve bellek

Derleme, shader önbelleği ve Windows işlemleri için yeterli boş alan ve bellek.

Rust

Projenin belirlediği Rust sürümü. Sürüm rust-toolchain.toml üzerinden seçilir.

Visual Studio araçları

MSVC C++ Build Tools ve Desktop development with C++ iş yükü.

Projeyi İndirme

1

Terminali açın

Windows Terminal veya PowerShell'i açın.

2

GitHub deposunu klonlayın

Aşağıdaki komut projeyi bilgisayara indirir.

git clone https://github.com/Marvisak/VIctory.git
3

Proje klasörüne girin

cd VIctory
4

Rust araçlarını hazırlayın

Proje, gerekli Rust sürümünü otomatik olarak indirebilir.

cargo xtask install-hooks

Proje Yapılandırması

Proje klasöründe örnek yapılandırma dosyasını kopyalayın. Ardından yeni dosyanın adının victory.toml olduğundan emin olun. 

copy victory.example.toml victory.toml

Daha sonra yapılandırma dosyasını açarak gerekli oyun dosyası yollarını düzenleyin. Dosyadaki ayarların nasıl yapılacağı için GitHub deposundaki güncel README açıklamalarını takip edin.

Proje yapılandırma komutunu çalıştırın:

cargo run -p victory -- config

Projenin testlerini çalıştırmak için:

cargo test --workspace

Projeyi Derleme

Gerekli araçlar ve yapılandırma tamamlandıktan sonra proje Release modunda derlenebilir. 

cargo build --release -p victory

Derleme tamamlandığında çalıştırılabilir dosya normalde aşağıdaki konumda oluşturulur: 

target\release\victory.exe
Not:

Derleme işlemi bilgisayarın donanımına ve gerekli bağımlılıkların durumuna göre uzun sürebilir. İlk derlemede Rust paketleri de indirilir.

Oyunu Çalıştırma

VIctory'nin çalıştırma aşaması, oyunun dosyalarına erişim ve shader çevirisi gerektirir. Aşağıdaki komutlar örnek değil, README'de belirtilen komut yapısıdır. Yer tutucular gerçek dosya yollarıyla değiştirilmelidir.

1. Shader ve pipeline çevirisi

target\release\victory.exe translate --cache --pipelines <game dir>\shaders.rpf <game dir>\<the title's exe> <game dir>\XboxBvhBuilder.dll <game dir>\amd_fidelityfx_upscaler_xbox.dll

<game dir> oyun dosyalarının bulunduğu klasörü, <the title's exe> ise oyunun çalıştırılabilir dosyasını temsil eder. Bu ifadeler doğrudan komuta yazılmamalı, gerçek yollarla değiştirilmelidir.

2. Oyunu başlatma

target\release\victory.exe run <game dir>\<the title's exe> --execute
Uzun işlem süreleri olabilir.

Shader çevirisi birkaç dakika sürebilir ve yaklaşık 1,3 GB önbellek oluşturabilir. Pipeline oluşturma işlemi yaklaşık 27.000 pipeline için 16 iş parçacığında yaklaşık 20 dakika sürebilir. Gerçek süre donanıma göre değişir.

Klavye Kontrolleri

XInput uyumlu bir kontrolcü bulunmadığında README'de belirtilen klavye eşleştirmeleri kullanılabilir.

  • WASD / IJKL: Sol ve sağ analog çubuklar
  • Yön tuşları: D-pad
  • Enter / Backspace: A / B
  • X / Y: X / Y
  • Q / E / Z / C: Omuz ve tetik tuşları
  • F / H: Analog çubuk basma
  • Esc / Tab: Menu / View

Karşılaşılabilecek Sorunlar

Windows hata kodu 1455

Bu hata sanal bellek veya Windows commit sınırıyla ilgili olabilir. Gereksiz uygulamaları kapatmak ve Windows sanal bellek ayarlarını kontrol etmek gerekebilir.

Ekran kartı sürücüsü sıfırlanıyor

Gerçek ekran kartları üzerinde çalıştırma sırasında sistem takılabilir veya ekran kartı sürücüsü sıfırlanabilir. Bu durum proje tarafından da belirtilen olası sorunlardan biridir.

Oyun çok yavaş çalışıyor

Proje henüz performans açısından tamamlanmış değildir. Oyun dünyasının çok düşük hızda görüntülenmesi mevcut geliştirme durumunda bilinen bir sınırlamadır.

Komut çalışmıyor

Komutların doğru klasörde çalıştırıldığını, Rust ve MSVC araçlarının kurulduğunu ve dosya yollarının doğru yazıldığını kontrol edin.

Projenin Mevcut Durumu

24 Kasım 2026 tarihli README bilgileri

  • Oyun başlatılabiliyor.
  • Menüler yaklaşık 30 FPS hızında çalışabiliyor.
  • Oyun dünyasının yüklenmesi yaklaşık 50 saniye sürebiliyor.
  • Dünya görüntülenebiliyor ancak kare süreleri çok yüksek.
  • Bazı yüzeyler ışıklandırılmıyor.
  • Uzak mesafedeki bazı geometriler eksik.
  • Bazı karakter görüntüleri hatalı.

Bu nedenle VIctory, şu anda GTA VI'yı Windows üzerinde normal şekilde oynamak için hazır bir çözüm değildir. Geliştirme aşamasında olan deneysel bir projedir.

Ayrıca proje tasarım gereği çevrimdışı çalışır; oyunun ağ bağlantısı kurmasına izin verilmez.
